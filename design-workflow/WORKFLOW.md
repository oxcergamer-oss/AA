# 工作流执行说明

## 阶段 0：目标定义
主责：设计总监 Agent。输入：业务目标、活动玩法、目标用户、渠道、周期、品牌资产、技术限制、奖品和数据指标。输出：活动 Brief、页面范围、核心转化链路、关键指标、优先级和风险清单。闸口 G0：目标、范围、成功标准明确。

## 阶段 1：体验架构
主责：交互设计师 Agent；设计总监 Agent 决策。输出：用户路径、页面流程图、页面清单、线框原型、信息架构、异常状态和埋点建议。闸口 G1：核心任务路径完整，玩法规则可理解，页面和状态没有明显断点。

## 阶段 2：视觉与色彩
主责：视觉设计师 Agent + 色彩系统设计师 Agent。输出：视觉方向稿、氛围基调、色板、字体层级、首页 Banner、头图、奖品区、按钮、弹窗、浮层和关键页面高保真稿。闸口 G2：设计总监确认视觉方向；色彩满足品牌一致性、可读性和状态区分要求。

## 阶段 3：规范与动效
主责：规范设计师 Agent + 动效设计师 Agent。输出：组件库、设计 Token、命名规范、响应式规则、状态表、动效说明、AE/网页动效参数和视频规格。闸口 G3：组件覆盖完整，命名和状态统一，动效可实现且不引入明显性能风险。

## 阶段 4：多端还原
主责：还原师 Agent。输入：高保真稿、组件规范、标注、切图、动效规格和技术约束。输出：分层资源、PNG/WebP、切图命名、尺寸标注、多端适配清单、还原差异清单和联调结论。重点检查：安全区、主流屏幕尺寸、横竖屏、触控热区、字体折行、弱网、懒加载、图片压缩和动效降级。闸口 G4：核心页面视觉还原和交互行为达到验收标准，P0/P1 问题清零。

## 阶段 5：联合验收
主责：设计总监 Agent；所有 Agent 参与。输出：验收记录、上线结论、遗留问题、监控指标和复盘事项。

## 返工规则
- P0：阻断核心流程、造成严重误解或无法上线。立即暂停下游并回退修复。
- P1：明显影响转化、可用性或品牌表现。回退至对应阶段闸口复审。
- P2：局部视觉或体验优化。不阻断上线，进入后续迭代池。
- 上游变更必须说明影响范围，并同步通知视觉、规范、还原和动效 Agent。
