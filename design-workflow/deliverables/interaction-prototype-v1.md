# 《失落星球：寻找能量晶》交互原型 V1

角色：交互设计师
版本：V1.0
页面：活动首页、邀请好友页、任务中心底部浮层

## 一、产品假设

- 用户身份：星球修复员。
- 核心目标：完成任务获取能量，探索星域并点亮星球。
- 核心资源：能量值用于探索，星尘用于成长，能量晶用于阶段收集和奖励。
- 好友机制：邀请协作者共同启动星核，邀请关系成立后增加协作进度。
- 首页主目标：让用户知道当前进度，并立即开始下一步行动。

## 二、全局页面关系

```text
活动首页
  ├─ 点击「开始探索」→ 执行探索任务 / 进入对应业务页
  ├─ 点击「任务」→ 打开任务中心底部浮层
  ├─ 点击「召集协作者」→ 进入邀请好友页
  ├─ 点击「奖励」→ 打开奖励详情弹窗
  └─ 点击「规则」→ 打开活动规则弹窗

邀请好友页
  ├─ 点击「召集协作者」→ 调起分享面板
  ├─ 好友完成助力 → 返回页内刷新协作进度
  └─ 点击返回 → 回到活动首页

任务中心底部浮层
  ├─ 点击「立即执行」→ 跳转任务目标页
  ├─ 点击「领取能量」→ 领取奖励并刷新首页
  ├─ 点击关闭/下滑 → 回到活动首页
  └─ 点击任务说明 → 打开任务规则说明
```

## 三、页面一：活动首页「星球修复舱」

### 页面目标

在首屏完成活动认知，展示星球修复进度，并引导用户执行唯一主操作：开始探索。

### 页面结构

```text
顶部导航
  返回 / 活动标题 / 规则

星球状态区
  星球当前形态
  修复进度：已点亮 X / Y 个星域
  当前等级与距离下一等级的星尘

阶段奖励区
  下一阶段奖励
  「还需点亮 X 个星域」

主操作区
  「开始探索」
  今日剩余探索次数

快捷入口区
  任务中心 / 召集协作者 / 能量晶收集

底部信息区
  活动时间 / 规则 / 客服或反馈
```

### 主要交互

1. 点击「开始探索」
   - 能量足够：进入探索或任务目标页。
   - 能量不足：打开「补充能量」弹窗，引导完成任务。
   - 无可探索区域：打开「星域完成」弹窗，引导查看奖励或邀请协作者。

2. 点击任务中心
   - 从底部展开任务浮层。
   - 首页保持原滚动位置，浮层关闭后回到原位置。

3. 点击「召集协作者」
   - 进入邀请好友页。
   - 若本轮星核已启动，按钮改为「查看协作进度」。

4. 点击阶段奖励
   - 打开奖励预览弹窗。
   - 弹窗显示获得条件、当前进度、奖励内容和下一步操作。

### 首页状态

| 状态 | 页面表现 | 主操作 |
| --- | --- | --- |
| 首次进入 | 星球处于未修复状态，展示新手提示 | 开始探索 |
| 可探索 | 显示可点亮星域和剩余次数 | 开始探索 |
| 能量不足 | 主按钮可点击，点击后提示补充能量 | 去做任务 |
| 修复中 | 显示当前进度和下一奖励 | 继续探索 |
| 阶段完成 | 星域点亮，展示阶段奖励 | 领取奖励 |
| 活动结束 | 保留已获得进度和奖励查询 | 查看奖励 |
| 网络异常 | 保留最近一次有效状态 | 重新加载 |

### 首页关键反馈

- 探索成功：能量晶飞入收集区，星域点亮，进度更新。
- 探索失败：说明失败原因，并给出「再试一次」或「去补充能量」。
- 升级成功：展示等级变化、星球形态变化和新解锁区域。
- 奖励到账：明确区分「已完成」和「已领取」。

## 四、页面二：邀请好友「星际协作站」

### 页面目标

让用户在 5 秒内理解邀请收益、有效助力条件和当前还差多少协作者，并完成分享。

### 页面结构

```text
顶部导航
  返回 / 星际协作 / 规则

星核状态区
  当前星核启动进度
  已有 X 位协作者 / 还需 Y 位
  星核能量轨道

邀请收益区
  我可获得：能量晶、星尘或阶段奖励
  协作者可获得：首次助力奖励

主操作区
  「召集协作者」
  复制邀请口令 / 分享链接

协作者列表
  已邀请 / 待完成 / 已助力 / 已失效

规则区
  有效邀请条件、活动期限、人数限制
```

### 主要交互

1. 点击「召集协作者」
   - 先显示按钮点击反馈。
   - 调起系统或 App 分享面板。
   - 分享成功后返回页面，状态变为「已发送，等待协作者完成助力」。
   - 用户取消分享不计入邀请，不改变进度。

2. 好友打开邀请链接
   - 未参与活动：展示活动简介和「接受协作」按钮。
   - 已参与活动：展示「完成协作」按钮。
   - 不符合条件：说明原因，不允许误显示为成功。

3. 点击协作者列表项
   - 展示该邀请当前状态和有效期。
   - 已失效项提供「重新邀请」。

4. 达到协作人数
   - 星核状态变为「已启动」。
   - 展示协作成功反馈。
   - 主按钮变为「领取协作奖励」或「继续探索」。

### 邀请状态

| 状态 | 文案 | 可用操作 |
| --- | --- | --- |
| 未邀请 | 还没有协作者加入 | 召集协作者 |
| 已发送 | 等待对方完成助力 | 查看分享状态 |
| 已打开 | 对方已进入，尚未完成条件 | 提醒协作者 |
| 已助力 | 协作成功 | 查看奖励 |
| 已失效 | 邀请已过期 | 重新邀请 |
| 重复助力 | 该用户已参与过 | 更换协作者 |
| 已达上限 | 本轮协作已完成 | 领取奖励 |

### 邀请成功反馈

```text
协作者完成助力
  ↓
星核新增一条能量轨道
  ↓
协作进度 +1
  ↓
双方奖励到账或进入待领取状态
```

## 五、页面三：任务中心底部浮层「每日能量任务」

### 页面目标

让用户快速查看任务、执行任务和领取奖励，不离开当前活动上下文。

### 默认形态

```text
半屏底部浮层
顶部圆角
背景遮罩
支持点击遮罩关闭、下滑关闭、返回键关闭
底部预留安全区
```

### 浮层结构

```text
拖拽指示条
标题：每日能量任务 / 今日已完成 X/Y
能量余额与刷新时间

任务列表
  任务图标
  任务名称
  完成条件
  可获得奖励
  当前进度
  操作按钮

底部提示
  任务每日刷新时间 / 任务规则
```

### 任务状态与按钮

| 任务状态 | 按钮 | 点击行为 |
| --- | --- | --- |
| 未开始 | 立即执行 | 跳转任务目标页 |
| 进行中 | 继续完成 | 回到任务目标页 |
| 已完成待领取 | 领取能量 | 发起领取并更新状态 |
| 已领取 | 已完成 | 不可点击 |
| 未解锁 | 暂未开放 | 展示解锁条件 |
| 已失效 | 已结束 | 不可点击并说明原因 |
| 接口加载中 | 加载中 | 暂时不可重复点击 |
| 接口失败 | 重试 | 重新请求任务状态 |

### 主要交互

1. 首页点击任务入口
   - 浮层从底部上移展开。
   - 背景加遮罩，焦点停留在浮层。

2. 点击「立即执行」
   - 记录任务点击。
   - 跳转到对应业务页面。
   - 返回活动页后重新校验任务状态，不直接按前端动画判定完成。

3. 点击「领取能量」
   - 按钮进入加载状态，防止重复领取。
   - 成功：展示获得能量反馈，任务变为「已完成」。
   - 失败：恢复按钮，提示失败原因和重试入口。

4. 点击关闭
   - 浮层退出，首页进度保持最新。
   - 如存在可领取任务，首页任务入口保留高亮标识。

### 任务完成反馈

```text
领取成功
  ↓
能量数值增加
  ↓
星球修复进度同步刷新
  ↓
若达到阶段条件，打开升级/奖励弹窗
```

## 六、关键异常与兜底

- 网络异常：展示具体原因，保留「重新加载」，不清空本地已展示进度。
- 重复点击：所有领取、分享、提交按钮进入 loading，接口返回前不可重复提交。
- 页面回流：从外部业务页返回后，统一重新拉取任务、资源和邀请状态。
- 奖励延迟：显示「奖励发放中」，禁止错误显示为已到账。
- 活动结束：停止主要操作，保留规则、进度和奖励查询。
- 资格不符：说明限制条件，不使用笼统的「操作失败」。
- 分享取消：不增加邀请人数，不弹出成功反馈。

## 七、交互验收标准

- 用户在首页 3 秒内理解当前目标和主按钮含义。
- 首页到任务浮层不超过 1 次点击，浮层到执行任务不超过 1 次点击。
- 邀请页明确展示邀请收益、有效条件、当前进度和失效规则。
- 完成任务、领取奖励、邀请成功三种状态不混淆。
- 所有异步操作都有 loading、成功、失败三类反馈。
- 页面返回后首页、邀请页和任务浮层的数据保持一致。
- 浮层关闭后不丢失首页滚动位置和用户当前上下文。
- 关键按钮文案与真实行为一致，不用“领取”代替“去完成”。

## 八、待产品确认项

- 探索是否是真实找物玩法，还是点击后进入任务闯关。
- 能量值、星尘、能量晶是否全部保留，还是只保留一种主资源。
- 邀请好友的有效条件和人数上限。
- 奖励是实物、权益、虚拟装扮还是抽奖资格。
- 任务完成后是否需要手动领取奖励。
- 活动是否需要排行榜、收集册或阶段榜单。
