# 视觉输出固定规则

- 所有运营活动移动端效果图固定输出为 `375×812px`。
- 默认输出 JPG；如需透明素材，另行输出 PNG。
- 角色素材必须保持原始形象、比例、颜色、五官和关键配件不变。
- 视觉参考火崽崽页面的设计方法：自然沉浸场景、大角色主视觉、柔和空气感、少量贴边入口、任务信息轻量叠加。
- 避免明显 AI 感：减少过度锐利的高光、玻璃质感、霓虹光效、复杂粒子和随机装饰。
- 背景元素控制在 3-5 类，保持前中后景关系，不堆叠星球、光环、闪点和卡片。
- 标题使用中等字重、圆润清晰的字形，避免过厚、过大、强描边和强发光。

- 首页 V16 风格已锁定为活动基准：暗调极光夜景 + 深靛蓝天空 + 青色极光 + 两侧暗树剪影 + 草地发光圆台；角色为粉色飞碟生物（锁定不变）。
- 奖励池条：单层半透明圆角玻璃条，表头「本期奖励池」，内部无边框小格。
- 主 CTA：扁平粉橙渐变胶囊 + 加粗白描边，仅靠色彩明暗做微弱体积感，文字极淡投影。
- 底部三入口：哑光软糖 3D 图标（不发光不高光），主标签蓝色粗白描边，副标签纯白小字无描边。
- 气泡：纯白圆角底 + 深蓝文字，无描边无投影。
- 邀请好友页等后续页面沿用该套风格：同一色系、同一光源、同一图标与文字规范，画布固定 375×812。
