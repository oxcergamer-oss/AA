# 原创活动视觉方向

参考来源：`D:\桌面\快手-火崽崽`
适用主题：`《失落星球：寻找能量晶》`
角色：视觉设计师

## 一、参考风格提炼

### 1. 高沉浸场景

参考页不是使用单色背景，而是用森林、沙漠、游乐设施等完整场景承载活动。场景承担世界观，UI 叠加在场景上，用户进入页面后先感知“我在哪里”。

### 2. 大角色中心

角色占据页面视觉中心，用表情和动作表达当前状态。角色不是静态装饰，而是任务、奖励和情绪反馈的主要载体。

### 3. 半透明信息层

顶部进度、任务区和浮层多使用白色半透明卡片或大圆角容器，在保留背景氛围的同时保证文字可读。

### 4. 强主按钮

核心操作使用大尺寸胶囊按钮，按钮内部同时展示动作和剩余资源，例如“开始探索 + 剩余次数”。

### 5. 多入口贴边布局

分享、规则、背包、装扮、排行榜等入口分布在页面边缘，中心区域保持给角色和主任务。入口图标采用高识别插画，不依赖复杂文字说明。

### 6. 任务与成长绑定

任务不仅显示“去完成”，还要说明完成后能获得什么，以及这些奖励如何改变角色、进度或场景。

## 二、原创转译原则

不能复用：

- 火崽崽角色、脸型、动作、服装和道具
- 夏令营、营地、森林、沙漠等原页面的具体场景组合
- 原页面的装扮商城、任务卡、按钮形状和入口位置
- 原有角色名称、活动口号和资产元素

可以学习：

- 场景化活动首页
- 角色作为情绪和状态反馈中心
- 半透明大卡片与大圆角系统
- 胶囊型主 CTA
- 任务、成长、奖励、收集之间的视觉闭环

## 三、《失落星球：寻找能量晶》视觉设定

### 核心场景

“星球修复舱”位于一颗正在复苏的星球表面。背景由星云、漂浮岛、能量轨道和未点亮的星域构成。随着任务完成，场景中的星域、轨道和能量晶逐步点亮。

### 原创角色

使用全新的“星核助手”或漂浮晶体生物，不采用动物、幼崽或现有 IP 形象。角色由一枚主晶体、环形轨道和可变化的光点组成，通过形态变化表现等级和情绪。

角色状态：

- 待机：环轨缓慢旋转
- 引导：向目标区域发射光线
- 成功：晶体展开，释放星尘
- 失败：光线减弱，显示补救路径
- 升级：轨道增加，星球区域点亮

## 四、三个页面的视觉排版

### 活动首页

```text
顶部：返回 / 活动标题 / 规则
上部：星球修复进度卡
中部：原创星核助手 + 星球场景
两侧：奖励、收集、协作入口
下部：大 CTA「开始探索」
底部：阶段奖励与任务入口
```

视觉重点是“角色在场景中修复星球”，而不是把角色单独放在白色卡片里。

### 邀请好友页

```text
顶部：星核启动标题
上部：协作进度与能量轨道
中部：星核助手发出召集信号
下部：奖励说明、协作者列表
底部：大 CTA「召集协作者」
```

好友加入后，视觉反馈应该是新增一条能量轨道或一颗协作星，不只是数字变化。

### 任务中心底部浮层

```text
背景：原页面降暗并保留场景轮廓
浮层顶部：拖拽条 / 任务标题 / 今日进度
任务卡：图标 / 任务描述 / 奖励 / 操作按钮
底部：刷新时间与规则说明
```

浮层参考“任务中心”的信息组织方式，但不复刻原页面的任务卡样式。任务状态通过图标、文字和按钮共同表达，不能只靠颜色区分。

## 五、视觉系统建议

### 色彩关系

- 场景底色：深蓝、星云紫、冷灰蓝
- 内容卡片：白色或低透明度雾面玻璃
- 探索状态：荧光青
- 奖励状态：暖黄色
- 主 CTA：能量橙
- 失败/警告：柔和珊瑚红

色彩应服务于状态，不做大面积无意义装饰。主按钮和奖励必须在背景中保持最高对比度。

### 组件特征

- 圆角：大圆角，统一卡片和浮层语气
- 按钮：胶囊型，动作词放在视觉中心
- 进度：轨道、能量线、星域节点
- 奖励：晶体、星尘、星章，不使用火花豆或营地徽章
- 图标：简洁的半立体图标，保持统一光源和材质

### 字体层级

- 活动标题：粗体、短句、允许轻微发光或描边
- 模块标题：中黑，保证远距离识别
- 任务说明：常规字重，控制在两行以内
- 数字和进度：加粗，使用独立视觉层级
- 规则文字：低对比度但不能低于可读范围

## 六、设计验收标准

- 首屏能看出“星球修复”而不是普通任务列表。
- 角色、进度、主 CTA 三者形成明确阅读路径。
- 场景细节不遮挡任务文字、按钮和倒计时。
- 所有入口在 375×812 页面中有稳定位置，不依赖背景插画定位。
- 任务完成后至少有一个非数字化反馈，例如星域点亮、轨道增加或角色形态变化。
- 不出现火崽崽、鹅、夏令营、营火、装扮商城等参考项目专属识别元素。
- 三个页面共享同一套圆角、光源、图标、按钮和进度组件。
