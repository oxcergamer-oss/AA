# 运营活动 UI 设计工作流 Subagent

这是一套用于电商、营销、增长、节日促销和品牌活动的 UI 设计协作工作流，覆盖 H5、App 内嵌活动页、Web 活动页和小程序等场景。

## 角色

1. 设计总监 Agent：目标、方向、创意评审、资源协调和阶段验收。
2. 交互设计师 Agent：需求分析、玩法拆解、流程、信息架构和交互原型。
3. 视觉设计师 Agent：活动页面完整视觉表现和活动氛围包装。
4. 色彩系统设计师 Agent：主色、辅助色、强调色、品牌融合和状态色。
5. 规范设计师 Agent：组件、Token、命名、字号、间距、状态和延展一致性。
6. 还原师 Agent：拆图、补图、切图、导出、标注和多端高保真还原。
7. 动效设计师 Agent：网页交互动效、AE 脚本动效和视频输出。

## 推荐调用方式

先调用设计总监 Agent 建立活动 Brief，再按 `workflow.yaml` 的阶段顺序调用下游 Agent。每个 Agent 必须引用上游结论，不得把未确认的假设当成需求事实。

## 统一交付规则

- 每次输出包含：结论、方案、依据、待确认项、风险、下一步动作。
- 页面和组件覆盖适用的默认、按压/悬停、禁用、加载、成功、错误和空状态。
- H5 和 App 内嵌页明确安全区、断点、触控尺寸、弱网降级和图片体积策略。
- P0/P1 问题回退到对应阶段闸口；P2 问题进入优化池，不阻断上线。
